# Student Management System (CLI)

Java console application to add, view, search, update and delete student records.
Uses OOP, ArrayList (Collection Framework) and file handling.

## How to run

Using IntelliJ IDEA:
1. Open the project folder in IntelliJ
2. Open Main.java and click the Run button

Using command line:
1. javac *.java
2. java Main

## Features
- Add student
- View all students
- Search student by ID
- Update student
- Delete student
- Data is saved in students.txt, so records stay after closing the program
